Documentação (arquitetura e áreas)

Este jogo foi concebido para ser simples, sem dependências. Os arquivos são:

  • index.html — marcação do jogo, áreas principais (tabuleiros, status, botão reiniciar) e a seção de documentação. IDs estáveis: player-board, computer-board, status, restart-button.
  • style.css — estilos para os tabuleiros (grid 10x10), estados das células (navio, acerto, erro, afundado) e layout responsivo simples.
  • game.js — toda a lógica do jogo: criação de tabuleiros 10x10, posicionamento aleatório de frota (porta-aviões 5, encouraçado 4, cruzador 3, submarino 3, destróier 2), detecção de acerto/erro/afundado, jogadas do jogador por clique, jogadas do computador por escolha aleatória de célula ainda não atingida, detecção de vitória/derrota e reinicialização.

Fluxos principais

  1. Ao iniciar: ambos os tabuleiros são gerados e as frotas posicionadas aleatoriamente sem sobreposição.
  2. Jogador clica em uma célula do tabuleiro do computador para atirar. A célula só pode ser atacada uma vez.
  3. Se houver navio: marca acerto e, se todas as células do navio estiverem atingidas, marca afundado. Mensagem aparece no elemento de status.
  4. Depois do jogador, o computador faz um tiro aleatório em uma célula ainda não atingida do tabuleiro do jogador. Mesmas regras de acerto/afundado se aplicam.
  5. Quando todas as embarcações de um lado forem afundadas, o jogo anuncia vitória/derrota e permite reiniciar.

Observações: o computador usa estratégia totalmente aleatória. Para QA, teste múltiplas partidas para validar que o posicionamento aleatório nunca sobrepõe navios e que os estados de célula (acerto/erro/afundado) atualizam corretamente.
